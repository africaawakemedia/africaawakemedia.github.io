# Africa Awake Media — Website starter

A responsive one-page website starter for AFRICA AWAKE MEDIA, with English, Hausa, French and Arabic language switching.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Use the language selector in the top-right corner.

## Before publishing
- Replace the sample email `hello@africaawakemedia.com` with an email address you own.
- Add your verified social media profile links.
- Replace sample story cards with researched, fact-checked articles.
- Confirm the final brand logo and domain name.
- The site currently uses Google Fonts; an internet connection is needed for those fonts. It still works with system fonts if offline.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — language switching and mobile menu

This is a starter site, not yet connected to a domain, CMS, analytics, newsletter, or hosting provider.
